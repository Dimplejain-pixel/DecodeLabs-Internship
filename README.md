# AI Chatbot

## Description

This is a Rule-Based AI Chatbot developed using Python. The chatbot responds to predefined user inputs using if-else conditions and runs continuously until the user chooses to exit.

## Features

* Handles greetings
* Responds to common questions
* Provides help commands
* Handles exit commands
* Uses rule-based decision making

## Technologies Used

* Python

## How to Run

1. Install Python.
2. Save the project as `chatbot.py`.
3. Open Terminal or Command Prompt.
4. Run the following command:

```bash
python chatbot.py
```

## Example

You: hello

Bot: Hello! How can I help you today?

You: bye

Bot: Goodbye! Have a nice day.
